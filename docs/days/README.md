# The days

One file per maker's run, twice a day (`YYYY-MM-DD-am.md`, `YYYY-MM-DD-pm.md`): the instructions the copies gave
Claude Code in that day of life (`NEEDS.md`, The maker's run, step 3). Each lists the open wishes for the game,
most backed first, with who wished and who backed them, what each would change in plain words, and the maker's
verdict; then what else in the shared journal was worth fixing. The PR of the run carries its file.
